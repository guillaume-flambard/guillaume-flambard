### What I'm working on

**[Echo Travel](https://echotravel.app)** — Speedboat booking platform for the Gulf of Thailand. Laravel, React, Inertia.js, real-time availability, multi-channel distribution. Handling thousands of passengers across Koh Samui, Koh Phangan, and Koh Tao.

**[liquid-ui](https://github.com/guillaume-flambard/liquid-ui)** — The first Apple Liquid Glass library for React. Authentic glassmorphism with environmental blending.

**[nope](https://github.com/guillaume-flambard/nope)** — Open-source AI that calls companies so you don't have to. Cancel subscriptions, negotiate bills, file complaints — hands free.
